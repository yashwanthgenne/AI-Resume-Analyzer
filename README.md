# AI Resume Analyzer

An AI-powered resume analysis application that compares a candidate's resume with a job description and provides skill matching, missing skill detection, match percentage, and AI-generated improvement suggestions.

## 🚀 Features

- Upload resume as PDF
- Upload job description as PDF
- Extract text from PDF documents
- Detect relevant technical skills
- Identify matching skills
- Identify missing skills
- Calculate a basic skill match percentage
- Generate AI-powered resume improvement suggestions
- Extract important keywords from the job description

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF2
- Google Gemini API
- python-dotenv
